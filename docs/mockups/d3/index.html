Welcome to DevDock

Start and stop your project's npm scripts from one place, without a terminal.

  1. Add a project folder. DevDock reads its package.json.
  2. Press Start on any script. Its output appears right below.
  3. Open your app in the browser when it's ready.

Scripts run with your Windows account's permissions. Only add projects you trust.
