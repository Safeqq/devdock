The target versions are exact development pins, not a claim that every Node.js 24 installation or OS version works. Windows through WSL does not count as native Windows evidence. The selected runner labels and architectures follow the [GitHub-hosted runners reference](https://docs.github.com/en/actions/reference/runners/github-hosted-runners); configured or skipped tests do not count as passing evidence. The selected SQLite API is currently marked Release Candidate in the [Node.js documentation](https://nodejs.org/download/release/latest-v24.x/docs/api/sqlite.html). Phase 7 and the full v1 roadmap are verified for the exact OS, image, architecture, and toolchain combinations recorded above.
